# 📊 Task Timer & Tracker App

The application supports user authentication via login, so that their details and information are stored.

It uses Chart.js to visualize tasks in a single chart, where users can input their daily tasks.

Each task can be timed, and users can compare its duration with other tasks.

The application stores this data per user, enabling daily comparisons of task performance.

The application is designed with an emphasis on style and visual appearance, using LESS to extend CSS.

Various dependencies are used ( angular-material, angular-animate ) to enhance the user interface (UI).

## 🛠️ Technologies Used

-AngularJS
-PHP
-SQL
-LESS
-HTML
-npm (package manager)
-Visual Studio Code (development environment)
